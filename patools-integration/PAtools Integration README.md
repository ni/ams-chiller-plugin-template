# PAtools Integration

[This](https://github.com/ni/ams-capabilities/blob/main/PAtools%20Integration%20README.md) document describes the process of integrating a new BLS plugin/Driver in PAtools using the Template_PowerSupply_BLS module. For a Chiller the steps are identical, instead of the Template_Power_Supply_BLS module the Template_Chiller_BLS module is used.
